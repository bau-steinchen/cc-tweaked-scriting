# CCTweaked Lua Scripts
This Repository contains the lua scripts that are used for my Minecraft Rail Yard Base Shunting

# Note
The Computer IDs and the configuration of the "side" for inputs/outputs ord peripherals is highly dependent on the Blocks placed in the Game.

The scripts are still under heavy development and can be changed over time

# Download
All scripts are also pushed to pastebin to download them via the pastebin programm in the cctweaked computer

[Pastebin Scripts](https://pastebin.com/u/bau-steinchen)

# Structure
```
Folder
├── base
│   └── not yet used
├── depo
│   └── scripts that are used to control my depo for waiting trains
├── schunting
│   └── scripts that are used for the whole shunting process inside my base
└── testing

```
